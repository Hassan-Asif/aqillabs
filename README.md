# AqilLabs One-Pager (Vue 3 + Vite)

A clean one-page website matching the mockup you shared:
- Sticky header
- Hero with CTA + wave background
- Recent Projects cards (demo images included)
- Why Choose Us section
- Contact section (WhatsApp + Email)
- Footer

## Setup

```bash
npm install
npm run dev
```

## Customize
Open `src/App.vue` and update:
- `email`
- `whatsapp`
- project titles/descriptions
- hero copy

Demo images live in `public/demos/` as SVG placeholders.
Replace them with your own screenshots whenever ready.

## Build
```bash
npm run build
npm run preview
```
